# 🛡️ نظام كشف الرسائل المشبوهة (Spam Email Detection)

## 📌 عن المشروع
هذا المشروع عبارة عن نموذج تعلم آلي (Machine Learning) مبني بلغة بايثون لاكتشاف وتصنيف الرسائل البريدية إلى رسائل سليمة (Ham) ورسائل احتيالية/مشبوهة (Spam). تم معالجة البيانات الخام واستخراج الميزات النصية لبناء نموذج قادر على تحليل النصوص واكتشاف الكلمات الدلالية للاحتيال.

## 🛠️ التقنيات والمكتبات المستخدمة
* **اللغة:** Python
* **معالجة البيانات:** Pandas, NumPy
* **التعلم الآلي:** Scikit-Learn (الخوارزمية المستخدمة: Multinomial Naive Bayes)
* **معالجة النصوص:** TF-IDF Vectorizer
* **الرسوم البيانية:** Matplotlib, Seaborn

## ⚙️ مراحل بناء النموذج
1. **قراءة البيانات:** استخراج عينة ضخمة من قاعدة بيانات (Enron Dataset).
2. **هندسة الميزات (Feature Engineering):** بناء عمود التصنيف برمجياً بناءً على الكلمات المفتاحية للاحتيال.
3. **تنظيف النصوص:** معالجة القيم الفارغة وتجهيز البيانات.
4. **تحويل النصوص (Vectorization):** تحويل الكلمات إلى أوزان رياضية باستخدام TF-IDF.
5. **التدريب والاختبار:** تقسيم البيانات (80% تدريب و 20% اختبار) وتدريب النموذج.
6. **التقييم:** استخراج دقة النموذج ومصفوفة الارتباك (Confusion Matrix).
